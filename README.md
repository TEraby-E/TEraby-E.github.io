# Terabyte 主页与学习手账

个人主页与学习记录工具。[个人主页](https://terabyte.top/) · [学习手账](https://terabyte.top/study/)

## 个人主页

集中展示个人信息、社交链接和学习资源。

## 学习手账

按当天日期展示各科学习任务，记录打卡状态与实际用时，汇总每日完成进度。

## 计划看板

按学科分栏管理完整学习计划，支持章节筛选、搜索、新建、编辑、删除和任务移动。看板与计划 JSON 共用一份数据。

## 历史记录

保存有打卡的学习日期及任务快照，可查看过去的学习内容、完成状态和用时。

## 账号与同步

每个账号拥有独立的计划、清单和历史记录。访客使用本机手账，登录账号支持跨设备同步和离线缓存。

## 数据文件

支持计划 JSON 的上传、下载、合并与替换，以及完整学习记录的备份和恢复。原始八科计划位于 [default-plan.json](study/plans/default-plan.json)。

## 图片导出

将当天或历史记录导出为图片，便于保存和分享。

## 离线与安装

缓存页面和计划资源，支持离线打卡、联网同步，以及通过支持的浏览器安装为桌面应用。
