第 42 题 · 单链表的公共后缀

给定两条带头结点的单链表。它们可能从某个数据结点开始共用同一条尾链。找出第一处共用的数据结点。结点是否相同由编号决定，与结点中的值无关。

输入
第一行三个整数 n、h1、h2，表示结点总数及两个不同的头结点编号。结点编号为 1 到 n。第二行按编号给出 n 个 next 值，0 表示空指针。两条链均无环，数据从各头结点的 next 开始。
输出
输出首个共用数据结点的编号。两条链没有公共结点时输出 0。
要求
设计时间上尽可能高效的算法，并说明时间复杂度。
原题 ↗

样例 1

输入
7 1 2
3 7 4 5 6 0 5
预期输出
5

样例 2

输入
6 2 1
6 3 5 0 0 4
预期输出
0

输出
输出一个整数，表示整棵树的带权路径长度。只有一个结点时，该结点深度为 0。
要求
给出二叉链表的结点类型，说明算法思路，并用 C/C++ 实现。
原题 ↗

样例 1

输入
5 1
0 2 3
3 0 0
0 4 5

2 0 0
预期输出
17

样例 2

输入

8 0 0
预期输出
0

第 41 题 · 表达式树转中缀式

把二叉表达式树转成中缀表达式。叶结点保存操作数，内部结点保存运算符。二元运算符两侧分别写左、右子表达式，一元负号写在右子表达式前。

输入
第一行两个整数 n、root，表示结点总数和根结点编号。随后按 1 到 n 的编号输入 n 行，每行依次为不含空格的 token、左孩子编号、右孩子编号。孩子编号为 0 表示不存在。叶结点没有孩子，一元负号只有右孩子，其他运算结点有两个孩子。
输出
输出一行中缀表达式，不含空格。每个非根运算结点形成的完整子表达式外加一对圆括号。根结点和叶结点自身不额外加括号。
要求
用括号保留树所确定的运算次序，同时处理一元负号和二元减号。给出设计思路与带关键注释的 C/C++ 实现。
原题 ↗

样例 1

输入
6 1
+ 2 3
* 4 5
- 0 6
2 0 0
x 0 0
y 0 0
预期输出
(2*x)+(-y)

样例 2

输入
7 3
4 0 0
/ 6 7
- 4 2
+ 1 5
x 0 0
8 0 0
2 0 0
预期输出
(4+x)-(8/2)

第 41 题 · 单链表首尾交替重排

线性表以带头结点的单链表存储。将原来的第一个、最后一个、第二个、倒数第二个结点依次接起来，直到全部结点用完。奇数长度时，中间结点排在最后。头结点不参加重排。

输入
第一行是结点数 n（n ≥ 1）。第二行是 n 个整数，按数据结点原顺序给出；据此建立链表。
输出

要求
重排应复用原有结点，只改链接。辅助空间为 O(1)，时间尽可能高效。输入建表和输出不计入重排的辅助空间。
原题 ↗

样例 1

输入
5
1 2 3 4 5
预期输出
1 5 2 4 3

样例 2

输入
4
9 9 -2 7
预期输出
9 7 9 -2

要求
允许负数和零，与原题样例一致。元素为 32 位有符号整数，距离按 64 位计算。算法应尽可能高效，分析其时空复杂度。
原题 ↗

样例 1

输入
3 4 5
-1 0 9
-25 -10 10 11
2 9 17 30 41
预期输出
2

样例 2

输入
2 2 2
1 4
2 4
0 4
预期输出
0

第 41 题 · 判定顺序存储的二叉搜索树

输入
第一行是数组长度 n。第二行有 n 个整数，结点值是正整数，−1 表示该位置没有结点。根位于下标 0，结点 i 的左右孩子位置分别是 2i+1 和 2i+2。越界位置视为空。
输出
符合条件输出 true，否则输出 false，均为小写。
要求
输入数组表示一棵合法的非空二叉树；空位置下没有有效结点。按严格的 BST 定义判断，相同的键不满足严格不等关系。
原题 ↗

样例 1

输入
7
4 2 6 -1 3 5 8
预期输出
true

样例 2

输入
7
8 4 12 -1 9 10 13
预期输出
false

第 41 题 · 二叉搜索树中最接近 K 的结点

要求
保证输入是一棵非空的严格二叉搜索树。K 和关键字均为 32 位有符号整数，差值按 64 位计算。
原题 ↗

样例 1

输入
7 9
8 4 12 2 6 10 14
预期输出
1
8 10

样例 2

输入
6 -1
3 -2 7 # -1 6
预期输出
